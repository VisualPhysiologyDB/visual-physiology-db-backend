# Follow-up feature proposals — not implemented

Effort is a rough engineering estimate including focused tests and curator review, assuming one developer familiar with this application. It is not a delivery commitment.

| Priority | Proposal and benefit | Concrete interaction | Effort | Dependencies |
|---|---|---|---|---|
| P1 | Citation export makes a filtered result set immediately usable in manuscripts. | Select references, download BibTeX/RIS, and choose record-based or DOI-deduplicated bibliography. Preserve non-DOI citations with an explicit completeness note. | 3–5 days | Recovered metadata; author/journal fields or cached bibliographic evidence; citation-format tests. |
| P1 | Shareable filtered views support collaboration and reproducibility. | “Copy view link” serializes tab, search, species, eye type and numeric ranges into validated URL parameters. Opening the link restores the filters and displays retrieval date. | 2–4 days | Current shared filter functions; versioned parameter schema. A saved snapshot would require a separate release system. |
| P2 | Public provenance inspection lets researchers assess whether a number supports their question. | Open an observation to see raw source columns, linked paper, source dataset/version, curator decisions, and field-specific evidence with private contacts omitted. | 5–8 days | Acuity provenance and reference audit now present; public audit redaction rules; equivalent source tracking for older assays. |
| P2 | Metadata-completeness indicators focus curator effort and reveal uncertainty. | Toggle “missing title”, “unverified method”, “unknown year”, or “unresolved taxonomy”; export a curation worklist. Never collapse these into a scientific quality score. | 3–5 days | New fields and reports; agreed definitions of completeness; admin filters. |
| P2 | Species comparison helps biologists explore variation without conflating different measurements. | Add 2–5 species to a comparison tray. Separate CPD from λmax, experimental from inferred values, and behavior from anatomical estimates; show observation counts, sources and condition caveats. | 2–3 weeks | Taxon curation and observation-level methods/conditions; no pooling across incomparable protocols. |
| P2 | Curation workflow for discovered publications closes the gap between accepting a paper and entering its data. | Curator accepts a candidate, assigns “data entry needed”, and sees a queue of accepted papers awaiting measurements. | 1–2 weeks | Separate discovery/review record and service identity proposed in the monthly-discovery design. |
| P3 | Observation-aware exploration invites users to understand visual diversity. | Pick an animal and explore acuity intervals alongside an illustrative spatial-frequency pattern; switch between documented observations with species, lighting and method context. | 1–2 weeks | Curator-approved explanatory text; careful distinction between an illustration and a reconstruction of an animal’s perception. |

The best two next steps are **shareable filtered views** and **citation export**. They directly extend interactions researchers already use, help users cite original studies, and have bounded implementation costs. Shareable filters can ship first. Citation export should follow author/journal recovery so the output is a usable bibliography. Public provenance is the next scientific reliability improvement, especially before species-comparison features.
