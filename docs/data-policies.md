# Scientific data and provenance policies

## Sources inspected

The local `giae073.pdf` is Frazer et al. (2024), [10.1093/gigascience/giae073](https://doi.org/10.1093/gigascience/giae073). Its methods distinguish heterologous expression, cell-level MSP and organ-level ERG and describe the `litsearch → references → experimental/sequence data` provenance chain. The frontend and web application's dependencies are independent of its research/ML environment.

The research repository was inspected selectively at [commit c2912f843b0dc520f7f8631d025d00c8c601fd6b](https://github.com/VisualPhysiologyDB/visual-physiology-opsin-db/tree/c2912f843b0dc520f7f8631d025d00c8c601fd6b). Its README describes versioned raw data and ML workflows; VPOD 1.3 raw `references.csv` has 111 rows with `refid`, `doi`, `searchid`. It is not the same reference inventory as this application's 597-row local CSV. No standalone visual-acuity dictionary/file was found in the inspected tree; do not silently substitute the research subset for this web application's data. All local reference and acuity rows, all column headers, method variants, numeric ranges, optional blanks, IDs and reference links were examined programmatically.

The Feller-associated comparative source is [Feller et al., Surf and turf vision, DOI 10.1016/j.asd.2020.101002](https://www.sciencedirect.com/science/article/pii/S1467803920301250), with [author-deposited Dryad data 10.5061/dryad.3n5tb2rdr](https://datadryad.org/dataset/doi%3A10.5061/dryad.3n5tb2rdr). Dryad identifies a literature-derived compound-eye survey and body length as a size covariate. Its metadata does not establish that every row of this enlarged VPOD acuity file follows one measurement protocol. The publisher's complete article fetch returned 403 in this environment; per-observation protocol verification remains a curator task. The supplied dataset includes non-compound-eye observations and later additions, so FellerRefID must not be used as a universal provenance key.

Standard angular notation is independently documented by [Schwarz, Narendra & Zeil, The properties of the visual system in the Australian desert ant Melophorus bagoti](https://pubmed.ncbi.nlm.nih.gov/21044895/) and [A new computational model illuminates the extraordinary eyes of Phronima](https://pmc.ncbi.nlm.nih.gov/articles/PMC9576097/): Δϕ denotes interommatidial angle and Δρ acceptance angle, both in degrees in the relevant measurements. [Caves et al., A customizable, low-cost optomotor apparatus](https://besjournals.onlinelibrary.wiley.com/doi/10.1111/2041-210X.13449) describes acuity in cycles per degree and distinguishes other angular units. These sources support field meanings, not undocumented conversion of this CSV's values.

## Visual acuity handling

- `BL (cm)` is stored as `body_length_cm`, using the supplied centimeter label and comparative source's body-length meaning. Standard/total/snout–vent length conventions are not supplied per row; none is assumed.
- `Δϕ (deg)` is the interommatidial angle; `Δρ (deg)` is the photoreceptor acceptance angle. Row-level optical axis, adaptation state, measurement/estimation procedure and full-width/half-width conventions have not been verified. The import flags this protocol uncertainty.
- CPD is spatial acuity in cycles per degree. All 546 supplied numeric CPD values are retained unchanged (range 0.02–160); three blank cells remain null. No `1/(2θ)` or other conversion is performed. Anatomical spacing, electrophysiological acceptance angle and behavioral thresholds can differ in biological meaning. The API does not assert that all CPD entries are direct behavioral measurements.
- Lens diameter is stored in millimeters exactly as labeled. The importer does not equate lens diameter with compound-eye facet diameter or estimate it from animal size.
- `Eye Type=NS` is retained literally; its expansion is not established by the available source documentation. Blank eye type remains null.
- `FellerRefID` is a retained source-local string. Only `refid` links to VPOD Reference. `(source_dataset, source_record_id)` identifies an observation; database `acuid` can differ from `acuID` when other records already exist.
- The complete source row, including Unicode header names, strings and empty cells, remains in `source_data`. `import_baseline` retains normalized values for safe three-way updates; it is admin-only. `quality_flags` is public so users can assess ambiguity.

Blank-genus rows are split only when Species is exactly a capitalized genus and lowercase species epithet (letters/hyphens). No genus is inferred from nearby rows. Ambiguous expressions such as “Trisopsis or Lestodiplosis sp.” remain in raw text with null normalized taxonomy. Already separated taxonomic text is trimmed and retained even if nonstandard; examples such as lowercase genus and `sp.` are flagged, not corrected. This import reports 82 rows with taxonomy warnings. Distinct records of one species are not collapsed.

New public observations require genus/species, a DOI or source URL and CPD; optional positive measurements can be omitted. There is no wavelength range check on acuity and no arbitrary upper scientific cap. Database constraints bound values by the largest finite IEEE double; validators reject zero, negative values, NaN and infinities. Legacy data with missing CPD is permitted by its stable source key. SQLite's driver can turn raw NaN into SQL NULL; the supported serializer/model paths reject it before persistence. Raw SQL/bulk writes are not a substitute for validation.

## Reference identifiers, dates and methods

Identifiers are classified before normalization as DOI, source URL, citation, malformed DOI candidate, placeholder or nonpublication source. DOI URL prefixes, case and percent-encoded slashes are normalized conservatively. A syntactically plausible identifier does not by itself establish a registry record. Bibliographic fields are populated only after exact DOI-provider agreement, or verified citation matching followed by exact DOI resolution. Citation acceptance requires title containment after punctuation/diacritic normalization, first author and year agreement, plus either the journal or volume and first page. Multiple matching candidates remain unresolved. Title-only similarity and the first search hit are never enough.

Raw DOI/citation/source text is copied to `raw_citation` before repairs. Safe HTTP(S) sources also occupy `source_url`. A known source warning `DOI WRONG` leaves the normalized DOI null and requires human review. Unresolved syntactically supplied DOIs may remain as supplied identifiers, with failed lookup evidence in the report; they are not counted as verified resolutions. Missing titles and recovered dates remain null when evidence is unavailable. Source-helper descriptions are useful provenance but do not authorize invented metadata or inferred methods.

Crossref `published-print` is selected before `published-online`, then `published`, then `issued`. Online and print dates are stored separately at the precision actually deposited. DataCite `Issued` is used if it is a valid partial date; otherwise `publicationYear` supplies year precision only. Crossref creation, deposit and index timestamps are never publication dates. Date ranges, malformed dates and season labels are not silently converted. Existing nonblank values are protected even if the provider disagrees; the conflict report contains both values and evidence. The histogram retains `year_of_publication` precedence to preserve curator decisions and old API compatibility; details expose the separately selected publication date.

`MOM` has 276 nonblank source cells; 13 are explicit NA labels and 263 produce retained method assertions. Spellings such as heterologous/heterolgous/Hetereologous map to “Heterologous expression”; `kintetics` maps to “Kinetics”; MSP, SCP and ERG remain distinct. Comma, semicolon and `//` separators retain multiple labels. `?` uncertainty is preserved. `CSP` is not silently interpreted as SCP. ISH, mutagenesis and kinetics are experimental-related techniques but do not establish a spectral/acuity measurement. Evolution, expression-domain descriptions and unspecified biochemistry remain unclassified. Computational inference is a separate kind. Empty/NA methods are unknown. The raw MOM remains available in the API/export.

No method is inferred from DOI metadata, inferred assay flags, paper title, or publication relevance. Source assertions are not newly verified experimental protocols. A methods filter or future comparison tool must retain this distinction.

## Counting and public rendering

Reference bars count records, including duplicate publications; multiple methods never multiply a record. The date precision and compatibility policy determine the histogram year; unknown years are excluded and reported. All years from minimum to maximum appear, including empty years. This is not a count of experiments or unique papers.

Acuity bars count observations. The actual range spans almost four orders of magnitude; a fixed linear width would hide the densely populated sub-CPD region. The UI therefore uses explicitly labeled **variable-width categorical intervals**, not an unlabeled log axis or a density estimate. Boundaries: 0, .05, .1, .2, .5, 1, 2, 5, 10, 20, 50, 100, 200, infinity. The upper end is exclusive, lower inclusive for positive values; zero is invalid. Empty intervals remain visible and final ≥200 overflow supports future data. Interpret bar heights as counts within those named intervals, not equal-width frequency density.

Tables, histograms, CSV downloads and copy use the same complete filtered approved population. Every API page is fetched, with same-origin pagination validation and cancellation when switching tabs. Pending/rejected records and private contacts are not part of this population. DOI/title truncation is visual only. Native details disclosures provide full text by keyboard/click/touch and titles also have hover text. External strings use DOM text nodes, links allow only HTTP(S), and new windows use `noopener noreferrer`. CSV strings are quoted, with a protective apostrophe for spreadsheet-formula-leading strings; API strings remain untouched.

## MSP/SCP repeats within a publication

The maintainer clarification supersedes unrestricted species/wavelength repeats: see [the corrected rule and examples](metadata-review.md#corrected-msp-duplicate-policy). `0010` retains source repeats through `duplicate_of` while allowing the same species and λmax from different publications. Public MSP tables, charts and exports count primary records only. This differs deliberately from reference histograms, which still count all public reference records, including duplicate publications.

Histogram display ranges follow the filtered data: omit empty leading/trailing bins, retain empty bins between populated bins, and preserve the original bin boundaries and plotted/excluded counts. With no plotted observations the displayed bin list is empty. This applies to wavelength and acuity plots; publication-year plots already span their observed years.
