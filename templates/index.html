How to cite us

Best Practices for Citing VPOD

  • Users should cite the VPOD and/or OPTICS paper.
  • Users must cite the specific version of VPOD/OPTICS used (note that the current version is v1.3).
  • If OPTICS was used, users must state the specific model used and whether the results were obtained using the bootstrapping option.
